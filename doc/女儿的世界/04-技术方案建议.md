# 04 · 技术方案建议

> 工程指导文档：单独起 repo 时按此实现。核心约束：**零构建、双击即用、离线可用、未来可转小程序**。

---

## 1. 技术选型

| 项 | 选择 | 理由 |
|----|------|------|
| 语言 | 原生 HTML + CSS + 原生 JS（ES6） | 零依赖、零构建，`file://` 双击即用 |
| 数据 | 单文件 `js/data.js`（`window.DATA = {...}` 全局对象） | 避免 fetch JSON 在 `file://` 下的 CORS 限制；内容与页面分离 |
| 主题 | CSS 变量 + `data-theme` 属性 + localStorage | 见 §3 |
| 持久化 | localStorage（档案、主题、学段偏好） | 无后端；隐私天然本地 |
| 图标/插画 | 内嵌 SVG + emoji | 离线可用、无资源加载失败风险 |
| 字体 | 系统字体栈优先，可选用「霞鹜文楷」本地打包 | 离线可用 |
| 路由 | 多页面（index / archive / module / glossary） | 语义化、可分享 URL；小程序 WebView 亦可直接承载 |

**明确不做**：框架、构建工具、后端、登录、数据库、CDN 依赖。

## 2. 数据 Schema（js/data.js）

```js
window.DATA = {
  // 女儿档案默认值（示例档案，家长可清空）
  archiveExample: {
    nickname: "小满", grade: "初二", tags: ["慢热", "细腻"],
    intro: "一个喜欢画画和看番的女孩",
    works: ["《排球少年》", "名侦探柯南"], idol: "时代少年团·丁程鑫",
    games: ["原神", "蛋仔派对"], music: "K-pop、周杰伦",
    recent: ["最近迷上了谷子，在攒吧唧"]
  },

  // 8 大模块
  modules: [
    {
      id: "anime-goods",            // 模块 id（URL 参数）
      title: "二次元与谷子文化",      // 模块名
      emoji: "🎀",                  // 图标
      color: "#F4A7B9",            // 模块专属色（见视觉规范 §7）
      tagline: "动漫、周边与她的角色朋友们",
      // 初中篇：三层内容
      middle: {
        what:   [ { title: "…", body: "…" }, … ],   // 2-4 个卡片
        why:    [ { title: "…", body: "…" }, … ],
        how:    { tips: ["话术1", "话术2"], advice: "相处建议…", redline: "红线提示…" }
      },
      // 高中篇：同结构
      high:   { what: […], why: […], how: { tips: […], advice: "…", redline: "…" } },
      // 本模块黑话（id 引用 glossary 词条）
      vocab: ["谷子", "吧唧", "痛包", "推し", "烫门", "冷门"]
    },
    // … 共 8 个模块
  ],

  // 黑话词典（≥40 条）
  glossary: [
    {
      term: "破防",                  // 词条
      meaning: "心理防线被击穿，情绪绷不住",
      reply: "「这都能破防？看来戳到你啦」",   // 家长接话
      module: "general",            // 来源模块分类
      hot: true                     // 是否高频词
    },
    // …
  ]
};
```

**模块内容三层结构约定**：

- `what`：数组卡片，每张卡片 = `{ title, body }`（概念/现象/术语各一卡）
- `why`：数组卡片（心理需求解读，每卡一个需求点：归属/认同/表达/解压/掌控感）
- `how`：对象
  - `tips[]`：话术示例（对话气泡展示，2-3 条）
  - `advice`：相处建议（一段话）
  - `redline`：红线提示（警示卡，一段话）

## 3. 主题系统实现

```html
<html lang="zh-CN" data-theme="journal">
```

```css
/* css/themes/journal.css —— 每套主题一个文件，只定义变量 */
:root[data-theme="journal"] {
  --bg: #FFF9F0; --primary: #F4A7B9; /* …完整 token 见视觉规范 §2 */
}
```

```js
// js/theme.js —— 3 个函数完成主题系统
function applyTheme(name) { document.documentElement.dataset.theme = name; localStorage.setItem("theme", name); }
function loadTheme() { applyTheme(localStorage.getItem("theme") || "journal"); }
// 主题切换器：渲染 4 个色卡 → 点击调用 applyTheme
```

**要点**：
- 模块专属色、贴纸标签色不随主题变化（品牌识别）
- 主题按钮悬浮层：4 色卡各展示「主色 + 名称 + 微缩预览（背景/卡片两色块）」
- `html` 上加 `data-theme`，避免主题切换闪烁（`<script>` 提前加载）

## 4. 档案系统实现（localStorage）

```js
// js/archive.js
const KEY = "daughter-archive-v1";
// 读写：localStorage.getItem(KEY) / setItem(KEY, JSON.stringify(archive))
// 结构：{ nickname, grade, tags[], intro, works[], idol, games, music, recent[], notes }
```

**行为约定**：
1. 首次进入：无档案 → 读取 `DATA.archiveExample` 渲染「示例档案」，档案页显示「这是示例，点这里换成真实信息」
2. 「清空示例」→ 删除 localStorage，回到示例引导
3. 年级字段（单选：初一~高三）→ 决定模块页默认学段（初一~初三 = 初中篇；高一~高三 = 高中篇）
4. 「最近在追」：支持追加记录（数组 push），显示为时间线样式（日期 + 内容）
5. 心情便签（notes）：仅档案页可见，界面文案注明「只给你自己看」
6. 所有写入即时生效并持久化；无云同步（v0.1）

## 5. 页面骨架与关键 JS

| 页面 | 关键逻辑 |
|------|---------|
| `index.html` | 渲染欢迎语（引用昵称）、今日小贴士（可从 data 随机/轮换）、档案卡摘要、8 模块网格、主题切换器 |
| `module.html?id=xxx` | 按 URL 参数加载模块；学段切换控件；三层内容渲染；「她的世界」专属卡（档案作品匹配模块关键词时显示）；本模块黑话列表 |
| `archive.html` | 阅读模式/编辑模式切换；表单字段与 §4 结构一致；时间线渲染 |
| `glossary.html` | 搜索即时过滤；模块分类 tab；词条卡展开「家长接话」 |

**URL 参数约定**：`module.html?id=anime-goods`；未知 id → 重定向首页。

**「她的世界」匹配规则（v0.1 简化版）**：档案字段（works/idol/games/music）包含模块关键词（如模块一的「番/动漫/漫画」、模块四的「原神/蛋仔」等）时，模块页顶部显示「小满的世界」卡片；无匹配则不显示。匹配词表放在 data.js 的 `modules[].keywords` 字段中。

## 6. 转小程序路线

**阶段判断**：先跑通 v0.1 Web 版并验证内容价值，再决定小程序化。

| 路线 | 做法 | 适用 |
|------|------|------|
| A. WebView 壳（最快） | 微信小程序 web-view 组件加载已部署的 H5 页面 | 内容型、无复杂交互；但 web-view 有域名白名单要求且体验受限 |
| B. uni-app 重写 | Vue 语法重写页面，一套代码出 H5 + 小程序 | 推荐：uni-app 生态成熟，静态数据方案可直接迁移 |
| C. Taro 重写 | React 语法，适合未来组件化扩展 | 若开发偏好 React 则选此项 |

**转小程序前的准备（v0.2 做）**：
- 部署静态站点到 HTTPS 域名（GitHub Pages / Vercel / 自有域名）
- 确认小程序类目（工具-亲子/教育类）
- 隐私合规：无用户信息收集（数据全本地），合规成本低

## 7. 性能与体验清单（v0.1 验收）

- [ ] `file://` 双击 index.html 全功能可用（无 fetch、无跨域问题）
- [ ] 首次加载无网络请求（字体系统回退、插画内嵌）
- [ ] 主题切换即时生效，刷新后记忆
- [ ] 档案编辑后刷新不丢失；清空示例可恢复引导
- [ ] 模块页 URL 可直接打开（深链可用）
- [ ] 移动端（375px 宽）阅读无横向滚动
- [ ] 全部文案无评判性语气（通读检查）
- [ ] 词典 ≥ 40 词条可搜索、可分类
