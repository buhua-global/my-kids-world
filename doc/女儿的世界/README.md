## 🎯 产品一句话

**以「通用少女文化科普」为骨架、以「女儿的个性化档案」为血肉，让家长在温暖的翻阅中，看懂女儿在追什么、为什么、以及怎么开口聊。**

## 🌈 核心设计原则

1. **有爱，不评判**：所有内容站在「理解」而非「纠正」的立场，尊重孩子的兴趣与选择
2. **懂文化，更懂心**：每个文化现象都解释背后的心理需求（归属感、认同、表达、解压）
3. **给方法，给话术**：不空讲道理，提供具体的沟通话术与相处建议
4. **分龄陪伴**：幼儿园篇/小学篇/初中篇/高中篇四档内容分层，对应孩子真实成长阶段
5. **私人定制**：女儿的档案可编辑，App 随女儿的成长一起更新
