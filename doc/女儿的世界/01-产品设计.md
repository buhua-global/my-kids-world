# 01 · 产品设计

## 1. 产品定位

**一句话**：以「通用少女文化科普」为骨架、以「女儿的个性化档案」为血肉，让家长在温暖的翻阅中，看懂女儿在追什么、为什么、以及怎么开口聊。

**产品类型**：响应式 Web App（先本地、后部署、可转小程序），无后端、无登录。

**情绪基调**：温暖、柔软、好奇、不评判。像翻开女儿的手帐本，而不是一份「青少年研究报告」。

---

## 2. 目标用户

| 维度 | 描述 |
|------|------|
| 主用户 | 10-18 岁女孩的爸爸妈妈（以妈妈为主，爸爸亦可） |
| 使用场景 | 睡前翻阅、女儿提起某个词时随手查、家庭旅行前想找共同话题 |
| 用户痛点 | ① 听不懂女儿的话（黑话、圈子）；② 不理解她的爱好，担心但不敢说；③ 想沟通但怕踩雷，不知如何开口 |
| 用户渴望 | ① 理解女儿的世界；② 找到安全的话题入口；③ 获得「被需要、被信任」的亲子关系 |

---

## 3. 价值主张

**对家长**：一本会生长的「女儿使用说明书」——看得懂、聊得来、爱得到位。

**对女儿（潜在）**：当她知道父母在认真了解她的世界，会感受到被尊重。App 本身不面向女儿，但它的存在方式（不评判、不窥探）要对得起女儿的信任。

---

## 4. 信息架构

```
首页 index.html
├── 欢迎语（温暖问候 + 今日小贴士卡片）
├── 女儿的小宇宙（档案卡：头像/昵称/年级/最近在追）
├── 8 大模块导航（手账网格卡片）
│   ├── 二次元与谷子文化
│   ├── 追星与偶像文化
│   ├── 网文与同人创作
│   ├── 游戏与虚拟世界
│   ├── 音乐与潮流
│   ├── 社交媒体与黑话词典
│   ├── 情感世界与心理状态
│   └── 梦想与自我认同
└── 写给家长的话（关于/初心）

模块详情页 module.html?id=xxx
├── 模块封面（emoji + 标题 + 一句话定位）
├── 学段切换（初中篇 / 高中篇）
│   └── 内容三层：这是什么 / 她为什么喜欢 / 怎么聊
│       ├── 是什么：概念、现象、术语卡片
│       ├── 为什么：心理需求解读（归属/认同/表达/解压）
│       └── 怎么聊：话术示例气泡 + 相处建议 + 红线提示
└── 相关黑话（本模块术语速查）

档案页 archive.html
├── 女儿的画像（昵称/年级/性格标签/一句话介绍）
├── 她的宇宙（喜欢作品、本命偶像、在玩游戏、追的番、听什么歌）
├── 最近在追（动态列表，家长随手记）
└── 心情便签（家长留言板，写给女儿的话）

黑话词典 glossary.html
├── 搜索框
├── 按模块分类的词条卡片（词 → 什么意思 → 家长怎么接话）
└── 来源标注（出自哪个圈子）
```

---

## 5. 页面流程

```
首页 → 点模块卡 → 模块详情页（默认按档案年级定位学段，可手动切换）
首页 → 点档案卡 → 档案页（编辑模式 / 阅读模式）
首页 → 黑话词典入口 → 词典页（搜索/分类）
任意页 → 右上角主题切换器 → 4 套主题实时预览切换（localStorage 记忆）
```

**学段定位逻辑**：档案中填写年级后，模块页默认展示对应学段（初中/高中）；未填写时默认展示「初中篇」并提示「去填女儿的年级，内容会更贴心」。

---

## 6. 交互设计要点

| 交互 | 说明 |
|------|------|
| 学段切换 | 模块页顶部「初中篇 / 高中篇」分段控件，切换后滚动位置保持在当前章节顶部 |
| 三层内容 | 同一页面纵向展开「是什么 → 为什么 → 怎么聊」，用视觉分隔（贴纸标签）区分三层 |
| 话术气泡 | 「怎么聊」中的建议话术以对话气泡样式呈现，家长可直接照着说 |
| 红线提示 | 「怎么聊」底部有「小心别踩雷」警示卡（如：不要突然翻女儿的手机） |
| 主题切换 | 右上角主题按钮 → 弹出 4 主题色板预览 → 点击应用；持久化到 localStorage |
| 档案编辑 | 「女儿的小宇宙」阅读模式 → 点「编辑」进入表单 → 保存后回阅读模式 |
| 词典查询 | 搜索即时过滤 + 分类 tab；词条可展开看「家长怎么接话」 |

**不做的（v0.1）**：登录、云同步、推送、已读标记、评论、多女儿档案（保持单档案，YAGNI）。

## 7. 女儿档案系统（「女儿的小宇宙」）

**意义**：通用内容 + 个性化档案 = 专属感与爱意的核心载体。

### 7.1 档案字段

| 字段 | 类型 | 示例 | 用途 |
|------|------|------|------|
| 昵称/小名 | 文本 | 小满 | 全局问候语引用 |
| 年级 | 单选 | 初二 | 学段定位（初中/高中） |
| 性格标签 | 多选 | 慢热、细腻、有主见 | 档案卡展示 |
| 一句话介绍 | 文本 | 一个喜欢画画和看番的女孩 | 档案卡引言 |
| 喜欢作品 | 多行文本 | 《排球少年》、名侦探柯南 | 模块页「关联她的世界」 |
| 本命偶像 | 文本 | 时代少年团·某某 | 同上 |
| 在玩游戏 | 文本 | 原神、蛋仔派对 | 同上 |
| 听什么歌 | 文本 | K-pop、周杰伦 | 同上 |
| 最近在追 | 多行文本 | 最近迷上了谷子，在攒吧唧 | 动态记录，可追加 |
| 心情便签 | 多行文本 | 写给女儿的话，家长自己存着 | 私密留言，不展示给孩子（仅家长可见） |

### 7.2 档案与内容的联动

- 档案年级 → 模块页默认学段
- 档案中的作品/偶像 → 模块详情页展示「她的世界」专属卡片（「小满最近在追《排球少年》」）
- 未填档案时 → 展示通用示例档案（「示例：小满，初二」）引导家长填写，一键「清空示例」

### 7.3 隐私与边界

- 所有数据仅存本地（localStorage），不上传、不联网
- 心情便签是家长私密空间，界面文案明确提示「这些话，只给你自己看」
- 产品价值观红线：**不做任何「分析女儿心理状态」的评判性结论**，只做理解与陪伴

## 8. 首页文案基调示例

> 欢迎语：「欢迎回家。这里不是调查问卷，是女儿世界的一扇小窗——慢慢看，不用急。」
>
> 今日小贴士：「她今天说的『破防』，可能不是生气，而是被戳中了。想接话？试试问：『这个梗在你们班流行吗？』」
>
> 档案卡：「小满的小宇宙 · 初二 · 最近在攒谷子」

## 9. 成功标准（v0.1 验收）

1. 本地双击 index.html 即可完整使用（零构建、零依赖）
2. 8 大模块全部有初中篇 + 高中篇内容（「是什么/为什么/怎么聊」三层完整）
3. 档案可编辑、可持久化、可清空示例
4. 4 套主题一键切换且刷新后记忆
5. 黑话词典 ≥ 40 个词条，可搜索
6. 全站文案无评判性语气，符合「有爱不评判」原则
