# 03 · 视觉设计规范

> 4 套主题（手账 / 梦幻 / 简约 / 复古），默认温暖手账风。
> 全部通过 CSS 变量（Design Token）实现，主题切换只需替换 `data-theme` 属性。
> 设计原则：温暖、柔软、手作感、有爱不评判。

---

## 1. 全局设计原则

1. **像手帐，不像 App**：圆角偏大、色彩柔和不刺眼、有贴纸与胶带元素；避免冷冰冰的深色大块面
2. **留白是呼吸**：卡片间距充足，文字行距 1.8+，不堆信息
3. **字是情绪**：标题用手写感字体，正文用圆润易读字体
4. **可爱的细节**：贴纸标签、虚线分隔、波浪线、小涂鸦点缀（SVG 内嵌，不依赖图片资源）
5. **深浅自知**：所有主题保证正文对比度 ≥ 4.5:1（WCAG AA），文字不用过浅的糖果色

## 3. 排版规范

| 层级 | 字号 | 字重 | 说明 |
|------|------|------|------|
| 页面大标题 | 28-32px | 粗/手写体 | 首页欢迎语、模块封面 |
| 区块标题 | 20-24px | 中粗 | 「是什么/为什么/怎么聊」标签 |
| 卡片标题 | 17-18px | 中 | 词条、模块卡 |
| 正文 | 15-16px | 常规 | 行距 1.8，段距 12px |
| 辅助文字 | 13px | 常规 | 来源、脚注 |
| 话术气泡文字 | 15px | 常规 | 白底气泡内 |

**中文字体栈建议**（本地优先，无网络依赖）：
- 标题手写体：`"LXGW WenKai", "霞鹜文楷", "STKaiti", "KaiTi", cursive`（可本地打包开源字体）
- 正文圆体：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", system-ui, sans-serif`

## 4. 组件规范

### 4.1 模块卡片（首页网格）
- 结构：emoji 图标 + 模块名 + 一句话定位 + 学段角标（初/高）
- 形态：圆角 20px，背景 `--card`，顶部 6px 彩色条带（每模块一个专属色，8 模块 8 色）
- 悬停：轻微上浮 4px + 阴影加深（`:hover` transform，尊重系统 reduce-motion）

### 4.2 贴纸标签（三层内容标识）
- 「是什么」→ 蓝色系贴纸（知道）：`📌 这是什么`
- 「为什么」→ 粉色系贴纸（懂心）：`💗 她为什么喜欢`
- 「怎么聊」→ 绿色系贴纸（行动）：`💬 怎么聊`
- 形态：圆角胶囊，浅底深字，左侧小图标，倾斜 2° 增加手作感

### 4.3 话术气泡（怎么聊）
- 形态：白底气泡 + 左侧圆角尾巴，仿聊天界面
- 前缀标签：「可以这样说」——家长可直接照读
- 多条话术纵向排列，间距 10px

### 4.4 红线提示卡（小心别踩雷）
- 形态：`--danger` 浅底 + 深色描边，图标 ⚠️ 或 💢 换为温柔的 🕊️/🪐 亦可
- 文案基调：提醒而非恐吓，如「先别急着纠正，她需要的是被理解」

### 4.5 学段分段控件（初中篇/高中篇）
- 形态：胶囊分段控件，选中态用 `--primary` 填充白字；未选中透明
- 语义：如果档案年级已填，对应学段默认高亮；带「推荐」小点提示

### 4.6 主题切换器（右上角）
- 形态：调色板按钮 → 弹出 4 个主题色卡（色卡展示主题主色 + 名称）
- 交互：点击即应用并持久化；当前主题有选中描边

### 4.7 档案卡（首页/档案页）
- 首页：横向卡片，头像圆（首字或 emoji）+ 昵称 + 年级 + 「最近在追」摘要 + 编辑入口
- 档案页：纵向展示全部字段；空字段显示引导文案「还没填，点这里告诉妈妈你在追什么」

### 4.8 词典词条卡
- 形态：词条名（粗体）+ 释义（正文）+ 「家长接话」浅色区块
- 搜索框：圆角胶囊，聚焦时 `--primary-soft` 底色

## 5. 插画与装饰资产建议

**原则**：全部使用内嵌 SVG / CSS 绘制，不依赖外部图片库（保证本地双击可用 + 离线可用）。

| 资产 | 建议实现 |
|------|---------|
| 首页 hero 插画 | 手绘风「打开的门/小窗」SVG，露出星星、书本、音符等女儿世界元素 |
| 贴纸装饰 | 8 个模块专属 emoji + SVG 贴纸（音符🎵、星星⭐、游戏🎮、书📖、相机📷…） |
| 分隔线 | CSS 虚线 / SVG 波浪线 |
| 背景纹理 | CSS `repeating-linear-gradient` 极淡网格 / 噪点（opacity < 0.03） |
| 头像占位 | 首字圆形 + 主题色，无图可用的兜底方案 |

**动效原则**：过渡 0.2s ease；尊重 `prefers-reduced-motion`；无弹跳式动画（保持安静温柔）。

---

## 6. 无障碍与响应式

- 响应式断点：< 480px 单列；480-900px 两列；> 900px 三列（模块网格）
- 触控目标 ≥ 44px（分段控件、主题按钮）
- 对比度：正文 ≥ 4.5:1；大字（24px+）≥ 3:1
- 语义化：页面使用 `<main>`、`<nav>`、`<article>`；词典用 `<dl>` 或带 aria 的卡片
- 动效：所有动画遵循 `prefers-reduced-motion`
