> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 doc/女儿的世界/ 四份设计文档落地 v0.1 本地版：零构建、双击 index.html 即用的静态 Web App（8 模块内容 + 档案系统 + 黑话词典 + 4 主题）。

**Architecture:** 原生 HTML/CSS/JS 多页面静态站；内容全部在 `js/data.js`（`window.DATA` 全局对象，规避 file:// CORS）；主题 = CSS 变量 + `data-theme` 属性 + localStorage；档案 = localStorage `daughter-archive-v1`；校验用 Node 脚本（仅开发期，不进产物）。

**Tech Stack:** HTML5 + CSS3（CSS 变量）+ ES6 原生 JS，Node ≥18（仅跑校验脚本），无任何运行时依赖。

**规范来源（唯一事实）：**

## 设计决策（锁定，执行时不再改）

1. **Schema**：按 doc 04 §2，学段键名定为 `junior`（初中篇）/ `senior`（高中篇）。`recent` 条目为 `{ text, date }`（date 为 ISO 日期或空串，空串渲染「早些时候」）。示例档案的 `idol/music` 为字符串，`works/games/tags/recent` 为数组。
2. **localStorage 键**：主题 `dw-theme`；档案 `daughter-archive-v1`（doc 04 §4 指定）。
3. **对比度修正**：doc 03 §1.5（对比度 ≥4.5:1）优先于 §4.5 的「选中态白字」——分段控件选中态用 `--primary` 填充 + `--text` 深色文字。
4. **模块专属色**：来自 doc 03 §7，随 `DATA.modules[].color` 注入 `style="--mcolor:…"`，不随主题变化。
5. **词典分类**：`glossary[].module` ∈ 8 个模块 id + `"general"`；`modules[].vocab[]` 引用的词必须存在于 glossary（校验脚本强制）。
6. **「她的世界」匹配**：档案 `works+idol+games+music` 拼接串包含 `module.keywords` 任一词即显示匹配卡（doc 04 §5）。
7. **XSS**：档案是用户输入，所有动态渲染一律过 `esc()`。
8. **学段默认**：初一~初三→junior，高一~高三→senior，未填→junior + 顶部提示去填年级（doc 01 §5）。
