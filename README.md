# 女儿的世界

> to know is to see —— 先看见，才理解。

给 10–18 岁女孩家长的「文化翻译小册子」：用孩子自己的方式认识她追的番、粉的人、玩的游戏、挂在嘴边的词。不评判任何喜好，不提供「改造方案」，只帮你看懂她的世界，让饭桌上的对话多一个开头。

## 如何使用

零构建、零依赖、完全离线：

1. 下载或克隆本仓库
2. **双击 `index.html`**（任何现代浏览器即可，支持 `file://` 直接打开）
3. 在「女儿的小宇宙」里填上她的喜好——所有信息只保存在你自己的浏览器（localStorage），不会上传，也没有算法

不填档案也能用：页面会展示一份示例档案。

## 功能

- **她的八个世界**：二次元与谷子、追星与偶像、网文与同人、游戏与虚拟、音乐与潮流、社交媒体、情感与心理、梦想与自我认同。每个世界分「初中篇 / 高中篇」，内容分三层：这是什么 → 她为什么喜欢 → 怎么聊（含开场话术、「可以这样做」与「小心别踩雷」）
- **小宇宙档案**：记下她的作品、爱豆、游戏、音乐、派系（学霸 / 二次元 / 地雷妹……）和「最近在追」，首页与模块页会据此提示「从哪里聊起最自然」
- **黑话词典**：60+ 个高频词（破防、谷子、本命、i人 e 人……），查意思、学接话
- **4 套主题**：柔和梦境 / 手账纸本 / 旧时光 / 极简白，选择记忆在本机

## 目录结构

```
index.html          首页
pages/              模块详情 / 小宇宙档案 / 黑话词典
js/data.js          全部内容数据（8 模块 × 2 学段 × 3 层 + 词典 + 话术）
js/theme.js         主题切换与记忆
js/archive.js       档案读写（localStorage）
js/ui.js + page-*.js 渲染与页面逻辑
css/themes/         4 套主题 Token
scripts/validate.mjs 内容数据校验（node scripts/validate.mjs）
doc/女儿的世界/      产品设计、内容大纲、视觉规范、技术方案
```
